# Project
Idea: LocalVault — A private local cloud storage app that turns any disk into your own cloud. No accounts, no subscriptions, no internet required. Files never leave your devices.
Platform: Flutter (Android, Windows, Linux, macOS, Raspberry Pi)

# Features (v2.3.0 — final polish wave)
1. Onboarding tooltips for feature discovery
2. Feature highlight cards with actions
3. Quick action floating buttons
4. Help center with searchable articles
5. FAQ accordion widget
6. Contact support button
7. LRU image cache with 50MB limit
8. Request batcher for efficient API calls
9. HTTP connection pool for connection reuse
10. Memory optimizer with GC and stats
