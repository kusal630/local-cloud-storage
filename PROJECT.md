# Project
Idea: LocalVault — A private local cloud storage app that turns any disk into your own cloud. No accounts, no subscriptions, no internet required. Files never leave your devices.
Platform: Flutter (Android, Windows, Linux, macOS, Raspberry Pi)

# Features (v2.0.0 — security & privacy wave)
1. Audit log viewer with filtering and search
2. Session manager showing all active devices
3. Security score indicator (0-100)
4. Security tips with actionable recommendations
5. Lazy loading system for large file lists (1000+ items)
6. Batch operations bar for multi-select file management
7. Enhanced image viewer with pinch-to-zoom and controls
8. Video player controls with progress bar and seeking
9. File info panel with metadata, checksum, and path
10. Haptic feedback system with distinct patterns
