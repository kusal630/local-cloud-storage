# Project
Idea: LocalVault — A private local cloud storage app that turns any disk into your own cloud. No accounts, no subscriptions, no internet required. Files never leave your devices.
Platform: Flutter (Android, Windows, Linux, macOS, Raspberry Pi)

# Features (v1.9.0 — performance & polish wave)
1. Lazy loading system for large file lists (1000+ items)
2. Batch operations bar for multi-select file management
3. Batch progress indicator for long operations
4. Enhanced image viewer with pinch-to-zoom and controls
5. Video player controls with progress bar and seeking
6. File info panel with metadata, checksum, and path
7. Animated list items with staggered entrance animations
8. Haptic feedback system with distinct patterns
9. AMOLED black mode for OLED power savings
10. Glassmorphism widgets with backdrop blur effects
